# Content Management

## Current State

Public listing data is served from Prisma. The seed creates an idempotent property type, permissions, roles, four enabled languages, and a published demonstration property.

## Publishing Safety

- Do not publish legal, tax, financial, or rent-rate claims without manual review.
- Imported third-party news must retain source name, URL, retrieval date, and draft status before publication.
- Keep only summaries in the platform and link to the approved original source.

## Current Limitation

The public blog is not yet backed by an admin CMS workflow. Magazine creation, translation, publishing states, source ingestion, and review controls must be implemented before editorial users can manage live content.
